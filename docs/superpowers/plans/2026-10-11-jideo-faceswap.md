# Jideo — face swap local (photo + vidéo) — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire Jideo, un service local (Docker, port 4545) qui fait du face swap sur photos et vidéos via une interface web.

**Architecture:** Un seul conteneur : FastAPI sert l'API et le frontend compilé (Vue 3). Un worker unique, dans un thread du même processus, consomme une file stockée dans SQLite et appelle le moteur IA (`app/engine/`, InsightFace + ONNX Runtime CPU, ffmpeg). La progression part vers le navigateur par SSE.

**Tech Stack:** Python 3.12, FastAPI 0.115, SQLite (stdlib), InsightFace 0.7.3 (`buffalo_l`, `inswapper_128`), ONNX Runtime 1.20 (CPU), GFPGAN 1.4 (ONNX), OpenCV, Pillow, ffmpeg ; Vue 3 + Vite 6 + Tailwind 4 ; pytest, Playwright ; Docker Compose.

## Global Constraints

- Port **4545** ; écoute hôte `JIDEO_BIND=127.0.0.1` par défaut ; toute autre adresse exige `JIDEO_PASSWORD` (sinon refus de démarrer) et `JIDEO_SECRET` ≥ 32 caractères.
- CPU uniquement : provider ONNX `CPUExecutionProvider` partout.
- Limites par défaut : `JIDEO_MAX_PHOTO_MB=25`, `JIDEO_MAX_VIDEO_MB=1024`, `JIDEO_MAX_VIDEO_SECONDS=300` (durée **traitée**, après découpage), photos réduites au-delà de **4096 px**, refus des tâches vidéo sous **2 Go** libres.
- `JIDEO_RETENTION_DAYS=30` (`0` = jamais), purge au démarrage puis toutes les **6 h**.
- Formats : photo `jpg/jpeg/png/webp`, vidéo `mp4/mov/webm/mkv`, vérifiés par OpenCV/ffprobe, pas seulement par l'extension.
- Seuil de similarité par défaut **0.35** ; amélioration GFPGAN par défaut **activée en photo, désactivée en vidéo/aperçu** ; filigrane visible **activé par défaut**.
- Métadonnée systématique `AI-generated by Jideo` (EXIF `ImageDescription` en JPEG/WebP, chunk texte `Description` en PNG, `comment` en MP4).
- Aperçu : priorité 10, autres tâches priorité 0 ; une seule tâche à la fois.
- Aucun appel réseau sortant hors `./jideo install` (téléchargement des modèles, SHA-256 vérifiés).
- Tous les messages destinés à l'utilisateur sont **en français**.
- Modèles dans `data/models/` : `models/buffalo_l/*.onnx`, `inswapper_128.onnx`, `gfpgan_1.4.onnx`.

## Review Focus

1. **Vidéo de téléphone avec métadonnée de rotation** : les dimensions annoncées, l'image extraite pour la détection et la vidéo produite doivent être dans le bon sens → test `test_rotated_video_is_handled_upright` (Task 7).
2. **WebM avec audio Opus** : la copie audio vers MP4 peut échouer → repli AAC, la vidéo garde son son → test `test_webm_with_opus_keeps_audio` (Task 7).
3. **Vidéo aux dimensions impaires** (ex. 321×241) : libx264/yuv420p exige des dimensions paires → sortie arrondie, pas d'échec d'encodage → test `test_odd_dimensions_are_made_even` (Task 7).
4. **Extension en majuscules** (`IMG_0001.JPG`, `Visage.PNG`) : doit être acceptée → test `test_upload_photo` utilise `Visage.PNG` (Task 9).
5. **Média supprimé alors qu'une tâche l'utilise** : la tâche échoue avec un message clair, sans trace Python → test `test_handler_fails_cleanly_when_target_media_was_deleted` (Task 8).

## Conventions d'exécution

- Toutes les commandes Python tournent **dans le conteneur** via `./jideo test …` (pytest) ; reconstruire l'image (`./jideo build`) après toute modification de `backend/requirements.txt` ou du `Dockerfile`.
- `./jideo test -m "not slow"` : tests rapides ; les tests `slow` utilisent les vrais modèles et sont ignorés si `data/models/` est incomplet.

```bash
#!/usr/bin/env bash
# Façade de Jideo — ./jideo help
set -euo pipefail
cd "$(dirname "$(readlink -f "$0")")"

compose() { docker compose "$@"; }
die() { echo "✗ $*" >&2; exit 1; }

ensure_env() {
  if [[ ! -f .env ]]; then
    cp .env.example .env
    local secret
    secret=$(python3 -c 'import secrets; print(secrets.token_hex(32))' 2>/dev/null || openssl rand -hex 32)
    sed -i "s/^JIDEO_SECRET=.*/JIDEO_SECRET=${secret}/" .env
    sed -i "s/^JIDEO_UID=.*/JIDEO_UID=$(id -u)/; s/^JIDEO_GID=.*/JIDEO_GID=$(id -g)/" .env
    echo "→ .env créé"
  fi
  mkdir -p data
}

url() {
  set -a; source .env; set +a
  local host="${JIDEO_BIND:-127.0.0.1}"
  [[ "$host" == "0.0.0.0" ]] && host="localhost"
  echo "http://${host}:${JIDEO_PORT:-4545}"
}

usage() {
  cat <<'EOF'
Usage : ./jideo <commande>
  install   crée .env, construit l'image, télécharge les modèles, démarre
  start     démarre Jideo
  stop      arrête Jideo
  restart   redémarre Jideo
  status    état du conteneur
  logs      suit les journaux
  shell     shell dans le conteneur
  build     reconstruit l'image
  test      lance pytest dans le conteneur (arguments transmis à pytest)
EOF
}

cmd="${1:-help}"; shift || true
case "$cmd" in
  install)
    command -v docker >/dev/null || die "Docker est requis"
    ensure_env
    compose build
    compose up -d
    echo "✓ Jideo tourne sur $(url)"
    ;;
  start)   ensure_env; compose up -d; echo "✓ Jideo tourne sur $(url)" ;;
  stop)    compose down ;;
  restart) compose restart ;;
  status)  compose ps ;;
  logs)    compose logs -f jideo ;;
  shell)   compose exec jideo bash ;;
  build)   ensure_env; compose build ;;
  test)    ensure_env; compose run --rm --no-deps jideo pytest "$@" ;;
  help)    usage ;;
  *)       usage; exit 1 ;;
esac
```

```python
"""Configuration de Jideo, lue une fois depuis l'environnement."""
from __future__ import annotations

import os
import secrets
from collections.abc import Mapping
from dataclasses import dataclass
from pathlib import Path

LOCAL_BINDS = {"127.0.0.1", "localhost", "::1"}


class ConfigError(RuntimeError):
    pass


@dataclass(frozen=True)
class Settings:
    data_dir: Path
    bind: str = "127.0.0.1"
    password: str | None = None
    secret: str = "jideo-local-secret-not-used-without-auth"
    max_photo_mb: int = 25
    max_video_mb: int = 1024
    max_video_seconds: int = 300
    retention_days: int = 30
    max_photo_side: int = 4096
    min_free_gb: float = 2.0

    @property
    def auth_required(self) -> bool:
        return self.bind not in LOCAL_BINDS

    @property
    def db_path(self) -> Path:
        return self.data_dir / "jideo.sqlite"


def load_settings(env: Mapping[str, str] | None = None) -> Settings:
    env = os.environ if env is None else env

    def integer(name: str, default: int) -> int:
        raw = env.get(name, "")
        if raw == "":
            return default
        try:
            return int(raw)
        except ValueError as exc:
            raise ConfigError(f"{name} doit être un entier (reçu {raw!r})") from exc

    settings = Settings(
        data_dir=Path(env.get("JIDEO_DATA_DIR", "data")).resolve(),
        bind=env.get("JIDEO_BIND", "127.0.0.1").strip() or "127.0.0.1",
        password=env.get("JIDEO_PASSWORD") or None,
        secret=env.get("JIDEO_SECRET") or secrets.token_hex(32),
        max_photo_mb=integer("JIDEO_MAX_PHOTO_MB", 25),
        max_video_mb=integer("JIDEO_MAX_VIDEO_MB", 1024),
        max_video_seconds=integer("JIDEO_MAX_VIDEO_SECONDS", 300),
        retention_days=integer("JIDEO_RETENTION_DAYS", 30),
    )
    if settings.auth_required:
        if not settings.password:
            raise ConfigError(
                f"JIDEO_BIND={settings.bind} expose Jideo au réseau : définissez JIDEO_PASSWORD dans .env"
            )
        if len(settings.secret) < 32:
            raise ConfigError("JIDEO_SECRET doit contenir au moins 32 caractères")
    return settings
```

```python
"""Accès SQLite. Une seule connexion partagée, protégée par un verrou."""
from __future__ import annotations

import json
import sqlite3
import threading
import time
import uuid
from pathlib import Path
from typing import Any

import numpy as np

SCHEMA = """
CREATE TABLE IF NOT EXISTS media (
    id TEXT PRIMARY KEY,
    kind TEXT NOT NULL,
    original_name TEXT NOT NULL,
    path TEXT NOT NULL,
    thumbnail_path TEXT,
    width INTEGER,
    height INTEGER,
    duration REAL,
    fps REAL,
    has_audio INTEGER,
    created_at REAL NOT NULL
);
CREATE TABLE IF NOT EXISTS faces (
    id TEXT PRIMARY KEY,
    media_id TEXT NOT NULL REFERENCES media(id) ON DELETE CASCADE,
    idx INTEGER NOT NULL,
    t REAL NOT NULL,
    bbox TEXT NOT NULL,
    score REAL NOT NULL,
    embedding BLOB NOT NULL,
    created_at REAL NOT NULL
);
CREATE TABLE IF NOT EXISTS jobs (
    id TEXT PRIMARY KEY,
    type TEXT NOT NULL,
    status TEXT NOT NULL,
    priority INTEGER NOT NULL DEFAULT 0,
    params TEXT NOT NULL,
    progress REAL NOT NULL DEFAULT 0,
    message TEXT,
    result_path TEXT,
    stats TEXT,
    created_at REAL NOT NULL,
    started_at REAL,
    finished_at REAL
);
CREATE INDEX IF NOT EXISTS jobs_queue ON jobs(status, priority DESC, created_at);
"""

JOB_FIELDS = {"status", "progress", "message", "result_path", "stats", "started_at", "finished_at"}


def new_id() -> str:
    return uuid.uuid4().hex


class Database:
    def __init__(self, path: Path) -> None:
        path.parent.mkdir(parents=True, exist_ok=True)
        self._conn = sqlite3.connect(path, check_same_thread=False, isolation_level=None)
        self._conn.row_factory = sqlite3.Row
        self._lock = threading.RLock()
        with self._lock:
            self._conn.execute("PRAGMA foreign_keys = ON")
            self._conn.execute("PRAGMA journal_mode = WAL")
            self._conn.executescript(SCHEMA)

    def close(self) -> None:
        with self._lock:
            self._conn.close()

    def _exec(self, sql: str, params: tuple = ()) -> sqlite3.Cursor:
        with self._lock:
            return self._conn.execute(sql, params)

    def _one(self, sql: str, params: tuple = ()) -> dict | None:
        with self._lock:
            row = self._conn.execute(sql, params).fetchone()
        return dict(row) if row else None

    def _all(self, sql: str, params: tuple = ()) -> list[dict]:
        with self._lock:
            rows = self._conn.execute(sql, params).fetchall()
        return [dict(r) for r in rows]

    # --- media -------------------------------------------------------------

    def insert_media(
        self, *, kind: str, original_name: str, path: Path | str, width: int, height: int,
        duration: float | None = None, fps: float | None = None, has_audio: bool | None = None,
        thumbnail_path: Path | str | None = None, media_id: str | None = None,
    ) -> dict:
        media_id = media_id or new_id()
        self._exec(
            "INSERT INTO media (id, kind, original_name, path, thumbnail_path, width, height,"
            " duration, fps, has_audio, created_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)",
            (media_id, kind, original_name, str(path), str(thumbnail_path) if thumbnail_path else None,
             width, height, duration, fps, None if has_audio is None else int(has_audio), time.time()),
        )
        return self.get_media(media_id)

    def get_media(self, media_id: str) -> dict | None:
        return self._one("SELECT * FROM media WHERE id = ?", (media_id,))

    def delete_media(self, media_id: str) -> None:
        self._exec("DELETE FROM media WHERE id = ?", (media_id,))

    # --- faces -------------------------------------------------------------

    def insert_face(
        self, *, media_id: str, index: int, t: float, bbox: tuple | list, score: float, embedding: np.ndarray,
    ) -> dict:
        face_id = new_id()
        self._exec(
            "INSERT INTO faces (id, media_id, idx, t, bbox, score, embedding, created_at)"
            " VALUES (?, ?, ?, ?, ?, ?, ?, ?)",
            (face_id, media_id, index, t, json.dumps([float(v) for v in bbox]), float(score),
             np.asarray(embedding, dtype=np.float32).tobytes(), time.time()),
        )
        return self.get_face(face_id)

    def get_face(self, face_id: str) -> dict | None:
        row = self._one("SELECT * FROM faces WHERE id = ?", (face_id,))
        if row:
            row["bbox"] = json.loads(row["bbox"])
            row["embedding"] = np.frombuffer(row["embedding"], dtype=np.float32).copy()
        return row

    # --- jobs --------------------------------------------------------------

    def insert_job(self, *, type: str, params: dict[str, Any], priority: int = 0) -> dict:
        job_id = new_id()
        self._exec(
            "INSERT INTO jobs (id, type, status, priority, params, created_at) VALUES (?, ?, 'queued', ?, ?, ?)",
            (job_id, type, priority, json.dumps(params), time.time()),
        )
        return self.get_job(job_id)

    @staticmethod
    def _job(row: dict | None) -> dict | None:
        if row:
            row["params"] = json.loads(row["params"])
            row["stats"] = json.loads(row["stats"]) if row["stats"] else None
        return row

    def get_job(self, job_id: str) -> dict | None:
        return self._job(self._one("SELECT * FROM jobs WHERE id = ?", (job_id,)))

    def list_jobs(self, limit: int = 50, offset: int = 0) -> list[dict]:
        rows = self._all(
            "SELECT * FROM jobs ORDER BY created_at DESC, rowid DESC LIMIT ? OFFSET ?", (limit, offset)
        )
        return [self._job(r) for r in rows]

    def claim_next_job(self) -> dict | None:
        with self._lock:
            row = self._conn.execute(
                "SELECT id FROM jobs WHERE status = 'queued' ORDER BY priority DESC, created_at, rowid LIMIT 1"
            ).fetchone()
            if row is None:
                return None
            self._conn.execute(
                "UPDATE jobs SET status = 'running', started_at = ?, progress = 0 WHERE id = ?",
                (time.time(), row["id"]),
            )
        return self.get_job(row["id"])

    def update_job(self, job_id: str, **fields: Any) -> None:
        unknown = set(fields) - JOB_FIELDS
        if unknown:
            raise ValueError(f"champs inconnus : {unknown}")
        if "stats" in fields:
            fields["stats"] = json.dumps(fields["stats"]) if fields["stats"] is not None else None
        if fields.get("result_path") is not None:
            fields["result_path"] = str(fields["result_path"])
        assignments = ", ".join(f"{name} = ?" for name in fields)
        self._exec(f"UPDATE jobs SET {assignments} WHERE id = ?", (*fields.values(), job_id))

    def cancel_queued_job(self, job_id: str) -> bool:
        cursor = self._exec(
            "UPDATE jobs SET status = 'cancelled', finished_at = ? WHERE id = ? AND status = 'queued'",
            (time.time(), job_id),
        )
        return cursor.rowcount == 1

    def delete_job(self, job_id: str) -> None:
        self._exec("DELETE FROM jobs WHERE id = ?", (job_id,))

    def mark_interrupted_jobs(self) -> int:
        cursor = self._exec(
            "UPDATE jobs SET status = 'failed', message = 'Interrompue par un redémarrage du serveur',"
            " finished_at = ? WHERE status = 'running'",
            (time.time(),),
        )
        return cursor.rowcount
```

```python
        return self.results / f"{job_id}{ext}"

    def job_tmp_dir(self, job_id: str) -> Path:
        directory = self.tmp / job_id
        directory.mkdir(parents=True, exist_ok=True)
        return directory

    def clear_job_tmp(self, job_id: str) -> None:
        shutil.rmtree(self.tmp / job_id, ignore_errors=True)

    def clear_tmp(self) -> None:
        for child in self.tmp.iterdir():
            if child.is_dir():
                shutil.rmtree(child, ignore_errors=True)
            else:
                child.unlink(missing_ok=True)

    def save_stream(self, src: BinaryIO, dest: Path, max_bytes: int) -> int:
        part = dest.with_name(dest.name + ".part")
        written = 0
        try:
            with part.open("wb") as out:
                while chunk := src.read(CHUNK):
                    written += len(chunk)
                    if written > max_bytes:
                        raise FileTooLarge(
                            f"Fichier trop volumineux (maximum {max_bytes // (1024 * 1024)} Mo)"
                        )
                    out.write(chunk)
            part.replace(dest)
        except BaseException:
            part.unlink(missing_ok=True)
            raise
        return written

    def delete(self, *paths: Path | str | None) -> None:
        for raw in paths:
            if not raw:
                continue
            path = Path(raw).resolve()
            if path.is_relative_to(self.root):
                path.unlink(missing_ok=True)

    def free_bytes(self) -> int:
        return shutil.disk_usage(self.root).free
```

```python
Usage : python -m app.engine.models download|check [--models-dir DIR]
"""
from __future__ import annotations

import argparse
import hashlib
import os
import shutil
import sys
import urllib.request
import zipfile
from dataclasses import dataclass
from pathlib import Path


class ModelChecksumError(RuntimeError):
    pass


@dataclass(frozen=True)
class ModelSpec:
    name: str
    url: str
    sha256: str
    required_files: tuple[str, ...]
    extract_to: str | None = None  # archive zip extraite dans models_dir/<extract_to>


MODEL_SPECS: tuple[ModelSpec, ...] = (
    ModelSpec(
        name="buffalo_l",
        url="https://github.com/deepinsight/insightface/releases/download/v0.7/buffalo_l.zip",
        sha256="",
        extract_to="models/buffalo_l",
        required_files=("models/buffalo_l/det_10g.onnx", "models/buffalo_l/w600k_r50.onnx"),
    ),
    ModelSpec(
        name="inswapper_128",
        url="https://huggingface.co/ezioruan/inswapper_128.onnx/resolve/main/inswapper_128.onnx",
        sha256="",
        required_files=("inswapper_128.onnx",),
    ),
    ModelSpec(
        name="gfpgan_1.4",
        url="https://github.com/facefusion/facefusion-assets/releases/download/models/gfpgan_1.4.onnx",
        sha256="",
        required_files=("gfpgan_1.4.onnx",),
    ),
)


def sha256_of(path: Path) -> str:
    digest = hashlib.sha256()
    with path.open("rb") as fh:
        while chunk := fh.read(1024 * 1024):
            digest.update(chunk)
    return digest.hexdigest()


def missing_models(models_dir: Path, specs: tuple[ModelSpec, ...] = MODEL_SPECS) -> list[str]:
    return [s.name for s in specs if not all((Path(models_dir) / f).is_file() for f in s.required_files)]


def _flatten(directory: Path) -> None:
    children = list(directory.iterdir())
    if len(children) == 1 and children[0].is_dir():
        inner = children[0]
        for item in inner.iterdir():
            item.rename(directory / item.name)
        inner.rmdir()


def download_model(spec: ModelSpec, models_dir: Path, *, log=print) -> str:
    models_dir = Path(models_dir)
    models_dir.mkdir(parents=True, exist_ok=True)
    part = models_dir / f"{spec.name}.download"
    log(f"↓ {spec.name} …")
    try:
        with urllib.request.urlopen(spec.url) as response, part.open("wb") as out:
            shutil.copyfileobj(response, out, 1024 * 1024)
        digest = sha256_of(part)
        if spec.sha256 and digest != spec.sha256:
            raise ModelChecksumError(
                f"{spec.name} : somme de contrôle invalide (attendu {spec.sha256}, obtenu {digest})"
            )
        if spec.extract_to:
            dest = models_dir / spec.extract_to
            shutil.rmtree(dest, ignore_errors=True)
            dest.mkdir(parents=True)
            with zipfile.ZipFile(part) as zf:
                zf.extractall(dest)
            _flatten(dest)
            part.unlink()
        else:
            part.replace(models_dir / spec.required_files[0])
    finally:
        part.unlink(missing_ok=True)
    log(f"✓ {spec.name} (sha256 {digest})")
    return digest


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(prog="python -m app.engine.models")
    parser.add_argument("command", choices=["download", "check"])
    parser.add_argument(
        "--models-dir", type=Path, default=Path(os.environ.get("JIDEO_DATA_DIR", "data")) / "models"
    )
    args = parser.parse_args(argv)
    missing = missing_models(args.models_dir)
    if args.command == "check":
        print("✓ Tous les modèles sont présents" if not missing else "✗ Manquants : " + ", ".join(missing))
        return 1 if missing else 0
    for spec in MODEL_SPECS:
        if spec.name in missing:
            download_model(spec, args.models_dir)
        else:
            print(f"✓ {spec.name} déjà présent")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Détection des visages et embeddings d'identité (InsightFace buffalo_l)."""
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

import numpy as np


@dataclass
class DetectedFace:
    bbox: tuple[float, float, float, float]
    score: float
    kps: np.ndarray        # (5, 2) float32 : yeux, nez, coins de la bouche
    embedding: np.ndarray  # (512,) float32, normalisé L2


def similarity(a: np.ndarray, b: np.ndarray) -> float:
    return float(np.dot(a, b))


class FaceDetector:
    def __init__(self, models_dir: Path, det_size: tuple[int, int] = (640, 640)) -> None:
        from insightface.app import FaceAnalysis

        self._app = FaceAnalysis(
            name="buffalo_l",
            root=str(models_dir),
            providers=["CPUExecutionProvider"],
            allowed_modules=["detection", "recognition"],
        )
        self._app.prepare(ctx_id=-1, det_size=det_size)

    def detect(self, img: np.ndarray) -> list[DetectedFace]:
        faces = [
            DetectedFace(
                bbox=tuple(float(v) for v in f.bbox),
                score=float(f.det_score),
                kps=np.asarray(f.kps, dtype=np.float32),
                embedding=np.asarray(f.normed_embedding, dtype=np.float32),
            )
            for f in self._app.get(img)
        ]
        faces.sort(key=lambda f: (f.bbox[0], f.bbox[1]))
        return faces
```

```python
"""Marquage des résultats : filigrane visible et métadonnée « généré par IA »."""
from __future__ import annotations

from pathlib import Path

import cv2
import numpy as np
from PIL import Image, PngImagePlugin

AI_NOTICE = "AI-generated by Jideo"
EXIF_IMAGE_DESCRIPTION = 0x010E


def add_visible_watermark(img: np.ndarray, text: str = "Jideo") -> np.ndarray:
    out = img.copy()
    h, w = out.shape[:2]
    scale = max(0.4, min(w, h) / 1200)
    thickness = max(1, round(scale * 2))
    font = cv2.FONT_HERSHEY_SIMPLEX
    (tw, _), _ = cv2.getTextSize(text, font, scale, thickness)
    margin = max(6, round(14 * scale))
    origin = (w - tw - margin, h - margin)
    overlay = out.copy()
    cv2.putText(overlay, text, origin, font, scale, (0, 0, 0), thickness + 2, cv2.LINE_AA)
    cv2.putText(overlay, text, origin, font, scale, (255, 255, 255), thickness, cv2.LINE_AA)
    return cv2.addWeighted(overlay, 0.6, out, 0.4, 0)


def save_image(img: np.ndarray, path: Path) -> None:
    pil = Image.fromarray(np.ascontiguousarray(img[:, :, ::-1]))
    if path.suffix.lower() == ".png":
        info = PngImagePlugin.PngInfo()
        info.add_text("Description", AI_NOTICE)
        pil.save(path, pnginfo=info)
        return
    exif = Image.Exif()
    exif[EXIF_IMAGE_DESCRIPTION] = AI_NOTICE
    pil.save(path, exif=exif.tobytes(), quality=95)
```

```python
"""Restauration du visage après swap (GFPGAN 1.4, ONNX, entrée 512×512)."""
from __future__ import annotations

from pathlib import Path

import cv2
import numpy as np

from app.engine.detector import DetectedFace

SIZE = 512
# Gabarit FFHQ 512 de facexlib : yeux, nez, coins de la bouche.
FFHQ_512 = np.array(
    [[192.98138, 239.94708], [318.90277, 240.19366], [256.63416, 314.01935],
     [201.26117, 371.41043], [313.08905, 371.15118]],
    dtype=np.float32,
)


def _paste_back(img: np.ndarray, crop: np.ndarray, matrix: np.ndarray, blend: float) -> np.ndarray:
    h, w = img.shape[:2]
    inverse = cv2.invertAffineTransform(matrix)
    warped = cv2.warpAffine(crop, inverse, (w, h), borderMode=cv2.BORDER_REPLICATE)
    mask = np.zeros((SIZE, SIZE), np.float32)
    margin = SIZE // 10
    mask[margin:-margin, margin:-margin] = 1.0
    mask = cv2.GaussianBlur(mask, (0, 0), sigmaX=SIZE / 20)
    mask = cv2.warpAffine(mask, inverse, (w, h))[..., None] * blend
    out = img.astype(np.float32) * (1 - mask) + warped.astype(np.float32) * mask
    return out.clip(0, 255).astype(np.uint8)


class FaceEnhancer:
    def __init__(self, model_path: Path, blend: float = 0.8) -> None:
        import onnxruntime as ort

        self._session = ort.InferenceSession(str(model_path), providers=["CPUExecutionProvider"])
        self._input = self._session.get_inputs()[0].name
        self._blend = blend

    def enhance(self, img: np.ndarray, face: DetectedFace) -> np.ndarray:
        matrix, _ = cv2.estimateAffinePartial2D(face.kps, FFHQ_512, method=cv2.LMEDS)
        crop = cv2.warpAffine(img, matrix, (SIZE, SIZE), borderMode=cv2.BORDER_REPLICATE)
        x = crop[:, :, ::-1].astype(np.float32) / 255.0
        x = (x - 0.5) / 0.5
        x = np.ascontiguousarray(x.transpose(2, 0, 1)[None])
        y = self._session.run(None, {self._input: x})[0][0]
        y = (np.clip(y, -1, 1) + 1) / 2
        restored = (y.transpose(1, 2, 0)[:, :, ::-1] * 255).round().astype(np.uint8)
        return _paste_back(img, restored, matrix, self._blend)
```

```python
"""Swap sur une image : détection → sélection → swap → amélioration → filigrane."""
from __future__ import annotations

from dataclasses import dataclass

import numpy as np

from app.engine.detector import DetectedFace, similarity
from app.engine.watermark import add_visible_watermark


@dataclass
class FrameResult:
    image: np.ndarray
    swapped: int


def match_faces(
    faces: list[DetectedFace], target_embeddings: list[np.ndarray] | None, threshold: float
) -> list[DetectedFace]:
    if target_embeddings is None:
        return list(faces)
    return [f for f in faces if any(similarity(f.embedding, t) >= threshold for t in target_embeddings)]


class FaceSwapPipeline:
    def __init__(self, detector, swapper, enhancer=None) -> None:
        self.detector = detector
        self.swapper = swapper
        self.enhancer = enhancer

    def process(
        self, img: np.ndarray, source_embedding: np.ndarray, target_embeddings: list[np.ndarray] | None,
        *, enhance: bool, watermark: bool, threshold: float,
    ) -> FrameResult:
        faces = match_faces(self.detector.detect(img), target_embeddings, threshold)
        out = img
        for face in faces:
            out = self.swapper.swap(out, face, source_embedding)
        if enhance and self.enhancer is not None:
            for face in faces:
                out = self.enhancer.enhance(out, face)
        if watermark:
            out = add_visible_watermark(out)
        return FrameResult(out, len(faces))
```

```python
"""Moteur IA : chargé une seule fois, à la première utilisation."""
from __future__ import annotations

import threading
from collections.abc import Callable
from dataclasses import dataclass, field
from pathlib import Path

from app.engine.models import missing_models
from app.engine.pipeline import FaceSwapPipeline
from app.errors import ModelsMissing


@dataclass
class Engine:
    detector: object
    swapper: object
    enhancer: object
    pipeline: FaceSwapPipeline = field(init=False)

    def __post_init__(self) -> None:
        self.pipeline = FaceSwapPipeline(self.detector, self.swapper, self.enhancer)

    @classmethod
    def load(cls, models_dir: Path) -> "Engine":
        from app.engine.detector import FaceDetector
        from app.engine.enhancer import FaceEnhancer
        from app.engine.swapper import FaceSwapper

        return cls(
            FaceDetector(models_dir),
            FaceSwapper(models_dir / "inswapper_128.onnx"),
            FaceEnhancer(models_dir / "gfpgan_1.4.onnx"),
        )


class EngineHolder:
    def __init__(self, models_dir: Path, loader: Callable[[Path], Engine] | None = None) -> None:
        self.models_dir = Path(models_dir)
        self._loader = loader or Engine.load
        self._engine = None
        self._lock = threading.Lock()

    def ready(self) -> bool:
        return self._engine is not None or not missing_models(self.models_dir)

    def get(self) -> Engine:
        with self._lock:
            if self._engine is None:
                missing = missing_models(self.models_dir)
                if missing:
                    raise ModelsMissing(f"Modèles absents ({', '.join(missing)}) : lancez ./jideo install")
                self._engine = self._loader(self.models_dir)
            return self._engine
```

```python
"""Vidéo : lecture en flux par ffmpeg, traitement image par image, réencodage + audio d'origine.

Aucune image intermédiaire n'est écrite sur disque.
"""
from __future__ import annotations

import json
import shutil
import subprocess
import time
from collections.abc import Callable
from dataclasses import dataclass
from pathlib import Path

import cv2
import numpy as np

from app.engine.watermark import AI_NOTICE
from app.errors import Cancelled, UserError

FrameFn = Callable[[np.ndarray], tuple[np.ndarray, bool]]


class VideoError(UserError):
    pass


@dataclass(frozen=True)
class VideoInfo:
    width: int
    height: int
    fps: float
    duration: float
    has_audio: bool


@dataclass(frozen=True)
class VideoStats:
    frames_total: int
    frames_with_face: int


def _run(cmd: list[str], error: str) -> subprocess.CompletedProcess:
    proc = subprocess.run(cmd, capture_output=True)
    if proc.returncode != 0:
        detail = proc.stderr.decode(errors="replace").strip().splitlines()[-1:] or [""]
        raise VideoError(f"{error} ({detail[0]})" if detail[0] else error)
    return proc


def _rate(value: str | None) -> float:
    if not value or "/" not in value:
        return float(value or 0)
    num, den = value.split("/")
    return float(num) / float(den) if float(den) else 0.0


def _rotation(stream: dict) -> int:
    for side in stream.get("side_data_list", []):
        if "rotation" in side:
            return int(float(side["rotation"]))
    return int(float(stream.get("tags", {}).get("rotate", 0)))


def probe(path: Path) -> VideoInfo:
    proc = _run(
        ["ffprobe", "-v", "error", "-print_format", "json", "-show_streams", "-show_format", str(path)],
        "Vidéo illisible",
    )
    data = json.loads(proc.stdout)
    streams = data.get("streams", [])
    video = next((s for s in streams if s.get("codec_type") == "video"), None)
    if video is None:
        raise VideoError("Aucune piste vidéo dans ce fichier")
    width, height = int(video["width"]), int(video["height"])
    if abs(_rotation(video)) % 180 == 90:  # ffmpeg applique la rotation au décodage
        width, height = height, width
    fps = _rate(video.get("avg_frame_rate")) or _rate(video.get("r_frame_rate"))
    duration = float(data.get("format", {}).get("duration") or video.get("duration") or 0)
    if fps <= 0 or duration <= 0:
        raise VideoError("Vidéo illisible (durée ou cadence inconnue)")
    return VideoInfo(
        width=width, height=height, fps=fps, duration=duration,
        has_audio=any(s.get("codec_type") == "audio" for s in streams),
    )


def extract_frame(path: Path, t: float) -> np.ndarray:
    proc = subprocess.run(
        ["ffmpeg", "-v", "error", "-ss", f"{max(0.0, t):.3f}", "-i", str(path),
         "-frames:v", "1", "-f", "image2pipe", "-vcodec", "png", "-"],
        capture_output=True,
    )
    img = cv2.imdecode(np.frombuffer(proc.stdout, np.uint8), cv2.IMREAD_COLOR) if proc.stdout else None
    if proc.returncode != 0 or img is None:
        raise VideoError(f"Impossible d'extraire une image à {t:.2f} s")
    return img


def make_thumbnail(path: Path, dest: Path, t: float = 0.0, width: int = 480) -> None:
    _run(
        ["ffmpeg", "-v", "error", "-y", "-ss", f"{t:.3f}", "-i", str(path),
         "-frames:v", "1", "-vf", f"scale={width}:-2", str(dest)],
        "Impossible de créer la miniature",
    )


def output_size(width: int, height: int, downscale_720p: bool) -> tuple[int, int]:
    if downscale_720p and min(width, height) > 720:
        ratio = 720 / min(width, height)
        width, height = round(width * ratio), round(height * ratio)
    return width - width % 2, height - height % 2


def _mux(video: Path, src: Path, start: float, duration: float, dst: Path,
         has_audio: bool, notice: str, tmp_dir: Path) -> None:
    part = tmp_dir / "muxed.mp4"
    meta = ["-metadata", f"comment={notice}", "-movflags", "+faststart"]
    if not has_audio:
        _run(["ffmpeg", "-v", "error", "-y", "-i", str(video), "-c:v", "copy", *meta, str(part)],
             "Échec de l'assemblage de la vidéo")
    else:
        base = ["ffmpeg", "-v", "error", "-y", "-i", str(video),
                "-ss", f"{start:.3f}", "-t", f"{duration:.3f}", "-i", str(src),
                "-map", "0:v:0", "-map", "1:a:0", "-c:v", "copy", "-shortest"]
        try:
            _run([*base, "-c:a", "copy", *meta, str(part)], "Copie de l'audio impossible")
        except VideoError:  # ex. Vorbis/Opus non accepté tel quel en MP4
            _run([*base, "-c:a", "aac", "-b:a", "192k", *meta, str(part)], "Échec de l'encodage audio")
    shutil.move(part, dst)


def process_video(
    src: Path, dst: Path, frame_fn: FrameFn, *, start: float = 0.0, end: float | None = None,
    downscale_720p: bool = False, tmp_dir: Path,
    on_progress: Callable[[int, int, float | None], None],
    should_cancel: Callable[[], bool], notice: str = AI_NOTICE,
) -> VideoStats:
    info = probe(src)
    start = max(0.0, start or 0.0)
    end = info.duration if end is None else min(end, info.duration)
    if end <= start:
        raise VideoError("Le segment choisi est vide")
    duration = end - start
    width, height = output_size(info.width, info.height, downscale_720p)
    total = max(1, round(duration * info.fps))
    frame_bytes = width * height * 3
    silent = tmp_dir / "video.mp4"

    decode = ["ffmpeg", "-v", "error", "-ss", f"{start:.3f}", "-t", f"{duration:.3f}", "-i", str(src),
              "-vf", f"fps={info.fps:.6f},scale={width}:{height}",
              "-f", "rawvideo", "-pix_fmt", "bgr24", "-"]
    encode = ["ffmpeg", "-v", "error", "-y", "-f", "rawvideo", "-pix_fmt", "bgr24",
              "-s", f"{width}x{height}", "-r", f"{info.fps:.6f}", "-i", "-",
              "-c:v", "libx264", "-preset", "medium", "-crf", "18", "-pix_fmt", "yuv420p", str(silent)]

    with (tmp_dir / "decode.log").open("wb") as dec_log, (tmp_dir / "encode.log").open("wb") as enc_log:
        dec = subprocess.Popen(decode, stdout=subprocess.PIPE, stderr=dec_log)
        enc = subprocess.Popen(encode, stdin=subprocess.PIPE, stderr=enc_log)
        done = matched = 0
        started = time.monotonic()
        try:
            while True:
                if should_cancel():
                    raise Cancelled()
                buf = dec.stdout.read(frame_bytes)
                if len(buf) < frame_bytes:
                    break
                frame = np.frombuffer(buf, np.uint8).reshape(height, width, 3).copy()
                out, found = frame_fn(frame)
                enc.stdin.write(np.ascontiguousarray(out).tobytes())
                done += 1
                matched += int(found)
                if done % 10 == 0:
                    elapsed = time.monotonic() - started
                    on_progress(done, max(total, done), done / elapsed if elapsed > 0 else None)
            enc.stdin.close()
            if enc.wait() != 0:
                raise VideoError("Échec de l'encodage vidéo")
            dec.wait()
        except BrokenPipeError as exc:
            raise VideoError("Échec de l'encodage vidéo") from exc
        finally:
            for proc in (dec, enc):
                if proc.poll() is None:
                    proc.kill()
                    proc.wait()

    if done == 0:
        raise VideoError("Aucune image n'a pu être lue dans ce segment")
    elapsed = time.monotonic() - started
    on_progress(done, done, done / elapsed if elapsed > 0 else None)
    _mux(silent, src, start, duration, dst, info.has_audio, notice, tmp_dir)
    return VideoStats(frames_total=done, frames_with_face=matched)
```

```python
"""Diffusion des événements de tâches vers les flux SSE (depuis n'importe quel thread)."""
from __future__ import annotations

import asyncio
import threading


def _put(queue: asyncio.Queue, event: dict) -> None:
    try:
        queue.put_nowait(event)
    except asyncio.QueueFull:
        pass  # client trop lent : il se resynchronisera via GET /api/jobs


class EventBus:
    def __init__(self) -> None:
        self._subscribers: set[asyncio.Queue] = set()
        self._loop: asyncio.AbstractEventLoop | None = None
        self._lock = threading.Lock()

    def bind_loop(self, loop: asyncio.AbstractEventLoop) -> None:
        self._loop = loop

    def subscribe(self) -> asyncio.Queue:
        queue: asyncio.Queue = asyncio.Queue(maxsize=1000)
        with self._lock:
            self._subscribers.add(queue)
        return queue

    def unsubscribe(self, queue: asyncio.Queue) -> None:
        with self._lock:
            self._subscribers.discard(queue)

    def publish(self, event: dict) -> None:
        loop = self._loop
        if loop is None or loop.is_closed():
            return
        with self._lock:
            subscribers = list(self._subscribers)
        for queue in subscribers:
            try:
                loop.call_soon_threadsafe(_put, queue, event)
            except RuntimeError:  # boucle arrêtée entre-temps
                return
```

```python
"""Worker unique : exécute les tâches une par une, dans un thread dédié."""
from __future__ import annotations

import logging
import threading
import time
from collections.abc import Callable
from dataclasses import dataclass, field
from pathlib import Path

from app.errors import Cancelled, UserError
from app.jobs.serialize import job_to_public

log = logging.getLogger("jideo.worker")


@dataclass
class JobResult:
    result_path: Path | None
    stats: dict = field(default_factory=dict)
    message: str | None = None


class JobContext:
    def __init__(self, job: dict, tmp_dir: Path, report: Callable, cancelled: Callable[[], bool]) -> None:
        self.job = job
        self.params = job["params"]
        self.tmp_dir = tmp_dir
        self._report = report
        self._cancelled = cancelled

    def report_progress(self, done: int, total: int, fps: float | None = None) -> None:
        self._report(done, total, fps)

    def should_cancel(self) -> bool:
        return self._cancelled()


Handler = Callable[[JobContext], JobResult]


class Worker:
    def __init__(self, db, storage, bus, handlers: dict[str, Handler]) -> None:
        self.db = db
        self.storage = storage
        self.bus = bus
        self.handlers = handlers
        self._cancel: set[str] = set()
        self._lock = threading.Lock()
        self._wakeup = threading.Event()
        self._stop = threading.Event()
        self._thread: threading.Thread | None = None

    def start(self) -> None:
        if self._thread is not None:
            return
        self._stop.clear()
        self._thread = threading.Thread(target=self._loop, name="jideo-worker", daemon=True)
        self._thread.start()

    def stop(self, timeout: float = 5.0) -> None:
        # La tâche en cours n'est pas annulée : au redémarrage elle sera marquée « interrompue ».
        self._stop.set()
        self._wakeup.set()
        if self._thread is not None:
            self._thread.join(timeout)
            self._thread = None

    def wake(self) -> None:
        self._wakeup.set()

    def cancel(self, job_id: str) -> bool:
        if self.db.cancel_queued_job(job_id):
            self._publish("cancelled", job_id)
            return True
        job = self.db.get_job(job_id)
        if job is not None and job["status"] == "running":
            with self._lock:
                self._cancel.add(job_id)
            return True
        return False

    def run_once(self) -> bool:
        job = self.db.claim_next_job()
        if job is None:
            return False
        self._execute(job)
        return True

    def _loop(self) -> None:
        while not self._stop.is_set():
            try:
                worked = self.run_once()
            except Exception:
                log.exception("Erreur du worker")
                worked = False
            if not worked:
                self._wakeup.wait(0.5)
                self._wakeup.clear()

    def _execute(self, job: dict) -> None:
        job_id = job["id"]
        self._publish("started", job_id)
        tmp_dir = self.storage.job_tmp_dir(job_id)
        started = time.monotonic()

        def report(done: int, total: int, fps: float | None) -> None:
            progress = min(1.0, done / total) if total else 0.0
            if fps is None:
                elapsed = time.monotonic() - started
                fps = done / elapsed if elapsed > 0 and done else None
            eta = (total - done) / fps if fps else None
            self.db.update_job(job_id, progress=progress)
            self.bus.publish({
                "type": "progress", "job_id": job_id, "progress": progress, "fps": fps,
                "eta_s": eta, "frames_done": done, "frames_total": total,
            })

        def cancelled() -> bool:
            with self._lock:
                return job_id in self._cancel

        handler = self.handlers.get(job["type"])
        try:
            if handler is None:
                raise UserError(f"Type de tâche inconnu : {job['type']}")
            result = handler(JobContext(job, tmp_dir, report, cancelled))
        except Cancelled:
            self.db.update_job(job_id, status="cancelled", finished_at=time.time())
            status = "cancelled"
        except UserError as exc:
            self.db.update_job(job_id, status="failed", message=exc.message, finished_at=time.time())
            status = "failed"
        except Exception as exc:
            log.exception("Tâche %s en échec", job_id)
            self.db.update_job(job_id, status="failed", message=f"Erreur interne : {exc}", finished_at=time.time())
            status = "failed"
        else:
            self.db.update_job(
                job_id, status="done", progress=1.0, result_path=result.result_path,
                stats=result.stats, message=result.message, finished_at=time.time(),
            )
            status = "done"
        finally:
            self.storage.clear_job_tmp(job_id)
            with self._lock:
                self._cancel.discard(job_id)
        self._publish(status, job_id)

    def _publish(self, event_type: str, job_id: str) -> None:
        job = self.db.get_job(job_id)
        if job is not None:
            self.bus.publish({"type": event_type, "job": job_to_public(job)})
```

```python
"""Traitements exécutés par le worker : photo, aperçu (une image de vidéo), vidéo."""
from __future__ import annotations

from pathlib import Path

import cv2
import numpy as np

from app.engine.video import extract_frame, process_video
from app.engine.watermark import save_image
from app.errors import UserError
from app.jobs.worker import Handler, JobContext, JobResult


def build_handlers(db, storage, engines, settings) -> dict[str, Handler]:
    def source_embedding(params: dict) -> np.ndarray:
        face = db.get_face(params["source_face_id"])
        if face is None:
            raise UserError("Visage source introuvable (média supprimé ?)")
        return face["embedding"]

    def target_embeddings(params: dict) -> list[np.ndarray] | None:
        if params["target_face_ids"] == "all":
            return None
        embeddings = []
        for face_id in params["target_face_ids"]:
            face = db.get_face(face_id)
            if face is None:
                raise UserError("Visage cible introuvable (média supprimé ?)")
            embeddings.append(face["embedding"])
        return embeddings

    def target_media(params: dict) -> dict:
        media = db.get_media(params["target_media_id"])
        if media is None or not Path(media["path"]).exists():
            raise UserError("Média cible introuvable (supprimé ?)")
        return media

    def swap_image(img: np.ndarray, params: dict):
        src = source_embedding(params)
        targets = target_embeddings(params)
        return engines.get().pipeline.process(
            img, src, targets, enhance=params["enhance"], watermark=params["watermark"],
            threshold=params["similarity_threshold"],
        )

    def photo(ctx: JobContext) -> JobResult:
        media = target_media(ctx.params)
        img = cv2.imread(media["path"], cv2.IMREAD_COLOR)
        if img is None:
            raise UserError("Image cible illisible")
        result = swap_image(img, ctx.params)
        if result.swapped == 0:
            raise UserError("Aucun des visages choisis n'a été retrouvé dans l'image cible")
        dest = storage.result_path(ctx.job["id"], Path(media["path"]).suffix.lower())
        save_image(result.image, dest)
        ctx.report_progress(1, 1)
        return JobResult(dest, {"faces_swapped": result.swapped})

    def preview(ctx: JobContext) -> JobResult:
        media = target_media(ctx.params)
        result = swap_image(extract_frame(Path(media["path"]), float(ctx.params.get("t", 0.0))), ctx.params)
        dest = storage.result_path(ctx.job["id"], ".jpg")
        save_image(result.image, dest)
        ctx.report_progress(1, 1)
        message = None if result.swapped else "Aucun visage correspondant sur cette image"
        return JobResult(dest, {"faces_swapped": result.swapped}, message)

    def video(ctx: JobContext) -> JobResult:
        if storage.free_bytes() < settings.min_free_gb * 1024**3:
            raise UserError(f"Espace disque insuffisant : moins de {settings.min_free_gb:g} Go libres")
        params = ctx.params
        media = target_media(params)
        src = source_embedding(params)
        targets = target_embeddings(params)
        pipeline = engines.get().pipeline

        def frame_fn(frame: np.ndarray) -> tuple[np.ndarray, bool]:
            r = pipeline.process(
                frame, src, targets, enhance=params["enhance"], watermark=params["watermark"],
                threshold=params["similarity_threshold"],
            )
            return r.image, r.swapped > 0

        trim = params.get("trim") or {}
        dest = storage.result_path(ctx.job["id"], ".mp4")
        stats = process_video(
            Path(media["path"]), dest, frame_fn,
            start=trim.get("start", 0.0), end=trim.get("end"),
            downscale_720p=params.get("downscale_720p", False), tmp_dir=ctx.tmp_dir,
            on_progress=ctx.report_progress, should_cancel=ctx.should_cancel,
        )
        ratio = round(100 * stats.frames_with_face / stats.frames_total)
        message = f"Visage cible trouvé sur {ratio} % des images seulement" if ratio < 50 else None
        return JobResult(
            dest, {"frames": stats.frames_total, "frames_with_face": stats.frames_with_face, "face_ratio": ratio},
            message,
        )

    return {"photo": photo, "preview": preview, "video": video}
```

```python
"""Inspection des fichiers envoyés : le contenu fait foi, pas l'extension."""
from __future__ import annotations

from pathlib import Path

import cv2

from app.engine.video import VideoError, make_thumbnail, probe
from app.errors import UnsupportedMedia


def inspect_photo(path: Path, max_side: int) -> dict:
    img = cv2.imread(str(path), cv2.IMREAD_COLOR)  # applique l'orientation EXIF
    if img is None:
        raise UnsupportedMedia("Image illisible ou corrompue")
    height, width = img.shape[:2]
    if max(width, height) > max_side:
        ratio = max_side / max(width, height)
        width, height = round(width * ratio), round(height * ratio)
        cv2.imwrite(str(path), cv2.resize(img, (width, height), interpolation=cv2.INTER_AREA))
    return {"width": width, "height": height}


def inspect_video(path: Path, thumbnail: Path) -> dict:
    try:
        info = probe(path)
        make_thumbnail(path, thumbnail)
    except VideoError as exc:
        raise UnsupportedMedia(f"Vidéo illisible ou corrompue : {exc.message}") from exc
    return {
        "width": info.width, "height": info.height, "duration": info.duration,
        "fps": info.fps, "has_audio": info.has_audio,
    }
```

```python
def create_app(settings: Settings | None = None, *, engines=None, start_worker: bool = True) -> FastAPI:
    logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(name)s: %(message)s")

    db = Database(settings.db_path)
    storage = Storage(settings.data_dir)
    engines = engines or EngineHolder(storage.models)
    bus = EventBus()
    worker = Worker(db, storage, bus, build_handlers(db, storage, engines, settings))

        db.mark_interrupted_jobs()
        storage.clear_tmp()
        if start_worker:
            worker.start()
        try:
            yield
        finally:
            worker.stop()

    app = FastAPI(title="Jideo", lifespan=lifespan)
    app.state.settings = settings
    app.state.db = db
    app.state.storage = storage
    app.state.engines = engines
    app.state.bus = bus
    app.state.worker = worker

    @app.get("/api/health")

        return {"status": "ok", "models_ready": engines.ready(), "auth_required": settings.auth_required}

    app.include_router(media.router)

    if STATIC_DIR.is_dir():
        app.mount("/", StaticFiles(directory=STATIC_DIR, html=True), name="static")
    return app
```

```python
"""Routes /api/jobs : création, suivi, annulation, relance, suppression, résultat."""
from __future__ import annotations

from pathlib import Path
from typing import Literal

from fastapi import APIRouter, Query, Request, Response
from fastapi.responses import FileResponse
from pydantic import BaseModel, Field

from app.api.media import clamp_time
from app.errors import Conflict, ModelsMissing, NotFound, UserError
from app.jobs.serialize import job_to_public

router = APIRouter(prefix="/api/jobs")
PRIORITY = {"preview": 10, "photo": 0, "video": 0}


class Trim(BaseModel):
    start: float = Field(0.0, ge=0)
    end: float | None = Field(None, gt=0)


class JobCreate(BaseModel):
    type: Literal["photo", "preview", "video"]
    source_face_id: str
    target_media_id: str
    target_face_ids: list[str] | Literal["all"] = "all"
    enhance: bool | None = None
    watermark: bool = True
    similarity_threshold: float = Field(0.35, ge=0.0, le=1.0)
    t: float = Field(0.0, ge=0)
    trim: Trim | None = None
    downscale_720p: bool = False


def get_job_or_404(request: Request, job_id: str) -> dict:
    job = request.app.state.db.get_job(job_id)
    if job is None:
        raise NotFound("Tâche introuvable")
    return job


def validate(body: JobCreate, request: Request) -> dict:
    state = request.app.state
    db = state.db
    if not state.engines.ready():
        raise ModelsMissing("Modèles absents : lancez ./jideo install")
    media = db.get_media(body.target_media_id)
    if media is None:
        raise NotFound("Média cible introuvable")
    if db.get_face(body.source_face_id) is None:
        raise NotFound("Visage source introuvable")
    expected = "photo" if body.type == "photo" else "video"
    if media["kind"] != expected:
        raise UserError("Ce traitement attend une photo" if expected == "photo" else "Ce traitement attend une vidéo")
    if body.target_face_ids != "all":
        if not body.target_face_ids:
            raise UserError("Choisissez au moins un visage cible")
        for face_id in body.target_face_ids:
            face = db.get_face(face_id)
            if face is None or face["media_id"] != media["id"]:
                raise UserError("Visage cible inconnu pour ce média")

    params = body.model_dump(exclude={"type"})
    params["enhance"] = (body.type == "photo") if body.enhance is None else body.enhance
    if body.type == "preview":
        params["t"] = clamp_time(media, body.t)
    if body.type == "video":
        duration = media["duration"] or 0.0
        start = body.trim.start if body.trim else 0.0
        end = min(body.trim.end if body.trim and body.trim.end else duration, duration)
        if end - start <= 0:
            raise UserError("Le segment choisi est vide")
        limit = state.settings.max_video_seconds
        if end - start > limit:
            raise UserError(
                f"La durée à traiter ({end - start:.0f} s) dépasse la limite de {limit} s : "
                "choisissez un extrait plus court"
            )
        params["trim"] = {"start": start, "end": end}
    return params


def enqueue(request: Request, job_type: str, params: dict) -> dict:
    state = request.app.state
    job = state.db.insert_job(type=job_type, params=params, priority=PRIORITY[job_type])
    public = job_to_public(job)
    state.bus.publish({"type": "queued", "job": public})
    state.worker.wake()
    return public


@router.post("", status_code=201)
def create_job(body: JobCreate, request: Request) -> dict:
    return enqueue(request, body.type, validate(body, request))


@router.get("")
def list_jobs(request: Request, limit: int = Query(50, ge=1, le=200), offset: int = Query(0, ge=0)) -> dict:
    return {"items": [job_to_public(j) for j in request.app.state.db.list_jobs(limit, offset)]}


@router.get("/{job_id}")
def get_job(job_id: str, request: Request) -> dict:
    return job_to_public(get_job_or_404(request, job_id))


@router.post("/{job_id}/cancel")
def cancel_job(job_id: str, request: Request) -> dict:
    get_job_or_404(request, job_id)
    if not request.app.state.worker.cancel(job_id):
        raise Conflict("Cette tâche est déjà terminée")
    return job_to_public(get_job_or_404(request, job_id))


@router.post("/{job_id}/retry", status_code=201)
def retry_job(job_id: str, request: Request) -> dict:
    job = get_job_or_404(request, job_id)
    if job["status"] not in ("failed", "cancelled"):
        raise Conflict("Seule une tâche en échec ou annulée peut être relancée")
    return enqueue(request, job["type"], job["params"])


@router.delete("/{job_id}", status_code=204)
def delete_job(job_id: str, request: Request) -> Response:
    state = request.app.state
    job = get_job_or_404(request, job_id)
    if job["status"] in ("queued", "running"):
        raise Conflict("Annulez la tâche avant de la supprimer")
    state.storage.delete(job["result_path"])
    state.db.delete_job(job_id)
    return Response(status_code=204)


@router.get("/{job_id}/result")
def job_result(job_id: str, request: Request) -> FileResponse:
    job = get_job_or_404(request, job_id)
    path = job["result_path"]
    if job["status"] != "done" or not path or not Path(path).exists():
        raise NotFound("Aucun résultat pour cette tâche")
    return FileResponse(path, filename=f"jideo-{job_id[:8]}{Path(path).suffix}")
```

```python
from __future__ import annotations

import asyncio
import json
from collections.abc import AsyncIterator, Awaitable, Callable

from fastapi import APIRouter, Request
from fastapi.responses import StreamingResponse

router = APIRouter()


async def event_stream(
    bus, is_disconnected: Callable[[], Awaitable[bool]], ping_interval: float = 15.0
) -> AsyncIterator[str]:
    queue = bus.subscribe()
    try:
        yield ": connected\n\n"
        while not await is_disconnected():
            try:
                event = await asyncio.wait_for(queue.get(), timeout=ping_interval)
            except asyncio.TimeoutError:
                yield ": ping\n\n"
                continue
            yield f"data: {json.dumps(event)}\n\n"
    finally:
        bus.unsubscribe(queue)


@router.get("/api/events")
async def events(request: Request) -> StreamingResponse:
    return StreamingResponse(
        event_stream(request.app.state.bus, request.is_disconnected),
        media_type="text/event-stream",
        headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"},
    )
```

```ts
async function request<T>(url: string, init?: RequestInit): Promise<T> {
  const res = await fetch(url, init)
```

```ts
import { reactive, ref } from 'vue'
import { api, type Job, type ProgressEvent } from '../api'

const jobs = ref<Job[]>([])
const progress = reactive<Record<string, ProgressEvent>>({})
let source: EventSource | null = null

function upsert(job: Job) {
  const index = jobs.value.findIndex((j) => j.id === job.id)
  if (index === -1) jobs.value.unshift(job)
  else jobs.value[index] = job
}

function remove(id: string) {
  jobs.value = jobs.value.filter((j) => j.id !== id)
  delete progress[id]
}

async function refresh() {
  jobs.value = (await api.listJobs()).items
}

function connect() {
  if (source) return
  source = new EventSource('/api/events')
  source.onmessage = (message) => {
    const event = JSON.parse(message.data)
    if (event.type === 'progress') {
      progress[event.job_id] = event
    } else if (event.job) {
      upsert(event.job)
      if (event.type !== 'started') delete progress[event.job.id]
    }
  }
  // EventSource se reconnecte seul ; on resynchronise la liste après une coupure.
  source.onerror = () => setTimeout(() => refresh().catch(() => {}), 2000)
}

export function useJobs() {
  return { jobs, progress, refresh, connect, upsert, remove }
}
```

`backend/app/auth.py` :
```python
"""Mot de passe unique, obligatoire dès que Jideo écoute hors de localhost."""
from __future__ import annotations

import hmac
import time

from fastapi import APIRouter, Request, Response
from fastapi.responses import JSONResponse
from itsdangerous import BadSignature, URLSafeTimedSerializer
from pydantic import BaseModel

COOKIE = "jideo_session"
MAX_AGE = 30 * 24 * 3600
LOGIN_FAILURE_DELAY = 1.0  # ralentit les essais de mot de passe
PUBLIC_PATHS = {"/api/health", "/api/login", "/api/logout"}

router = APIRouter()


def _serializer(secret: str) -> URLSafeTimedSerializer:
    return URLSafeTimedSerializer(secret, salt="jideo-session")


def is_authenticated(request: Request) -> bool:
    settings = request.app.state.settings
    if not settings.auth_required:
        return True
    token = request.cookies.get(COOKIE)
    if not token:
        return False
    try:
        _serializer(settings.secret).loads(token, max_age=MAX_AGE)
    except BadSignature:
        return False
    return True


async def auth_middleware(request: Request, call_next):
    path = request.url.path
    if path.startswith("/api/") and path not in PUBLIC_PATHS and not is_authenticated(request):
        return JSONResponse({"detail": "Authentification requise"}, status_code=401)
    return await call_next(request)


class Login(BaseModel):
    password: str


@router.post("/api/login", status_code=204)
def login(body: Login, request: Request) -> Response:
    settings = request.app.state.settings
    if not settings.auth_required:
        return Response(status_code=204)
    if not hmac.compare_digest(body.password.encode(), settings.password.encode()):
        time.sleep(LOGIN_FAILURE_DELAY)
        return JSONResponse({"detail": "Mot de passe incorrect"}, status_code=401)
    response = Response(status_code=204)
    response.set_cookie(
        COOKIE, _serializer(settings.secret).dumps("ok"), max_age=MAX_AGE, httponly=True, samesite="lax"
    )
```

`backend/app/purge.py` :
```python
"""Suppression automatique des médias et résultats trop anciens."""
from __future__ import annotations

import logging
import threading
import time

log = logging.getLogger("jideo.purge")


def purge(db, storage, retention_days: int, *, now: float | None = None) -> dict:
    if retention_days <= 0:
        return {"jobs": 0, "media": 0}
    cutoff = (now if now is not None else time.time()) - retention_days * 86400
    jobs = media = 0
    for job in db.jobs_created_before(cutoff):
        storage.delete(job["result_path"])
        db.delete_job(job["id"])
        jobs += 1
    for item in db.media_created_before(cutoff):
        if db.media_in_use(item["id"]):
            continue
        storage.delete(item["path"], item["thumbnail_path"])
        db.delete_media(item["id"])
        media += 1
    return {"jobs": jobs, "media": media}


class PurgeThread:
    def __init__(self, db, storage, retention_days: int, interval_s: float = 6 * 3600) -> None:
        self.db = db
        self.storage = storage
        self.retention_days = retention_days
        self.interval_s = interval_s
        self._stop = threading.Event()
        self._thread: threading.Thread | None = None

    def start(self) -> None:
        if self._thread is None:
            self._stop.clear()
            self._thread = threading.Thread(target=self._loop, name="jideo-purge", daemon=True)
            self._thread.start()

    def stop(self) -> None:
        self._stop.set()
        if self._thread is not None:
            self._thread.join(2)
            self._thread = None

    def _loop(self) -> None:
        while not self._stop.is_set():
            try:
                removed = purge(self.db, self.storage, self.retention_days)
                if removed["jobs"] or removed["media"]:
                    log.info("Purge : %(jobs)s tâche(s), %(media)s média(s) supprimés", removed)
            except Exception:
                log.exception("Échec de la purge")
            self._stop.wait(self.interval_s)
```

````markdown
# Jideo

Face swap local sur photos et vidéos, avec une interface web sur le port 4545.
Tout tourne sur la machine (CPU) : aucune donnée ne part sur Internet après l'installation.

## Installation

Prérequis : Docker avec le plugin Compose.

```
./jideo install
```

La commande crée `.env`, construit l'image, télécharge les modèles (~1,2 Go, vérifiés par SHA-256) dans
`data/models/` et démarre Jideo sur http://127.0.0.1:4545.

## Commandes

| Commande | Effet |
|---|---|
| `./jideo start` / `stop` / `restart` | cycle de vie |
| `./jideo logs` | journaux |
| `./jideo test` | tests backend (`-m "not slow"` pour sauter ceux qui chargent les modèles) |
| `./jideo e2e` | test de bout en bout (Jideo doit tourner) |
| `./jideo build` | reconstruit l'image après une mise à jour |

## Configuration (`.env`)

| Variable | Défaut | Rôle |
|---|---|---|
| `JIDEO_BIND` | `127.0.0.1` | adresse d'écoute ; toute autre valeur exige `JIDEO_PASSWORD` |
| `JIDEO_PASSWORD` | vide | mot de passe de l'interface hors localhost |
| `JIDEO_MAX_PHOTO_MB` / `JIDEO_MAX_VIDEO_MB` | 25 / 1024 | taille maximale des fichiers |
| `JIDEO_MAX_VIDEO_SECONDS` | 300 | durée maximale **traitée** (après découpage) |
| `JIDEO_RETENTION_DAYS` | 30 | suppression automatique des fichiers (0 = jamais) |

## Performances (CPU)

- Photo : 1 à 3 s.
- Vidéo : environ 1 à 2 images/s sans amélioration, 0,3 à 0,5 avec. Une vidéo de 30 s à 30 i/s prend
  donc 8 à 15 min, ou 30 à 50 min avec l'amélioration. L'option « Réduire à 720p » accélère le rendu.

## Licences et usage responsable

- Les modèles InsightFace (`buffalo_l`, `inswapper_128`) sont réservés à un **usage non commercial**.
- Chaque résultat porte la métadonnée `AI-generated by Jideo` et, par défaut, un filigrane visible.
- N'utilisez Jideo que sur des visages de personnes qui y ont consenti.

## Documentation

- Conception : `docs/superpowers/specs/2026-10-11-jideo-faceswap-design.md`
- Plan d'implémentation : `docs/superpowers/plans/2026-10-11-jideo-faceswap.md`
````
